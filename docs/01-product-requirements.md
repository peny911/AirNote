# 01 · AirNote 产品需求规格书（PRD）

## 1. 产品定位与品牌命名

- **正式名称**：**`AirNote`**（纯英文、含 `Note` 字样、独立于具体视觉光效，传达轻盈、私密、有序的现代云端记事体验）。
- **品牌图标**：极简折纸翼（Floating Breeze Paper）几何徽标，浅色/深色背景均清晰可辨。
- **核心目标**：打造一款功能上对标 **Microsoft OneNote**（笔记本 → 分区 → 页面），同时在界面美感、轻快手感、移动端兼容与私有安全隔离上全面现代化的网页版网络记事本。

---

## 2. 核心功能范围

### 2.1 三级结构化笔记管理（OneNote 心智）
1. **笔记本（Notebook）**
   - 创建、重命名、自定义图标与主题色、排序、删除（二次确认）。
   - 每个用户拥有完全独立的笔记本集合。
2. **分区（Section）**
   - 隶属于特定笔记本，支持彩色宝石视觉标识（8 套高辨识度协调色板）。
   - 创建、重命名、修改颜色、排序、删除（支持批量处理其下页面）。
   - 支持单笔记本内承载大量分区（如 20–30+ 分区）而不影响查找效率。
3. **页面（Page）与子页面（Sub-page）**
   - 隶属于特定分区，支持二级/多级缩进子页面嵌套。
   - 富文本编辑：大标题、多级标题（H1/H2/H3）、加粗/斜体/下划线/删除线、高亮、无序/有序列表、可勾选待办清单、高亮提示卡片（Callout）、语法代码块、表格、分割线、图片粘贴与本地附件上传。
   - **无感防抖自动保存**：停止输入约 500–600ms 自动保存，顶部显示实时同步状态。
   - **页面管理**：星标置顶、跨分区移动、拖拽排序、软删除进入回收站（支持恢复与彻底清除）。
4. **全局速搜**
   - 桌面端 `⌘K` / `Ctrl+K`、移动端右上角搜索按钮唤起全局检索，基于 SQLite FTS5 实现标题与正文的毫秒级模糊检索，点击直达目标页面。

### 2.2 用户账号与封闭邀请制
1. **必须登录才能使用**：未登录状态下访问任何页面或 API 均重定向/返回 401。
2. **禁止自助注册**：不提供注册页面或公开注册接口。
3. **管理员建号机制**：
   - 系统首次启动时通过 CLI 初始化脚本创建首位超级管理员账号。
   - 仅 `role = 'admin'` 的管理员可进入「管理员控制台」执行：
     - 创建新用户（输入姓名、登录账号/邮箱、角色，系统生成高强度一次性初始密码供复制分发）；
     - 启用 / 停用用户账号（停用时立即吊销该用户所有活跃 Session）；
     - 为用户重置密码；
     - 为遗失手机的用户解绑/重置 2FA；
     - 查看安全审计日志（登录成功/失败、2FA 校验拦截、管理员操作记录）。
4. **严格多用户数据隔离**：
   - 每个用户只能查看、搜索、编辑、下载**自己名下**的笔记本、分区、页面与附件。
   - 管理员控制台仅管账号生命周期，**应用层与 API 均不提供管理员查看其他用户笔记内容的入口**。

### 2.3 双因素身份认证（2FA）策略（已定稿）
- **开启策略**：**非强制，允许用户登录后按需自主开启或关闭**。
- **协议兼容**：标准 RFC 6238 TOTP（SHA-1、6 位数字、30 秒周期），100% 兼容 **Google Authenticator**、**Microsoft Authenticator** 等主流密码器。
- **完整生命周期**：
  - 未开启 2FA 的用户：登录时输入账号密码直接进入工作区。
  - 开启 2FA：在「个人头像 → 安全与 2FA 设置」打开开关 → 桌面端扫码（手机端优先「一键复制 Base32 密钥」+ `otpauth://` 链接）→ 输入 6 位实时动态码校验生效 → 展示并提示保存 **8 组一次性备用恢复码**。
  - 已开启 2FA 登录：密码校验通过后进入 6 位动态验证码步骤，支持退格、自动跳格、整段粘贴，并支持切换「8 位备用恢复码」登录。
  - 关闭 2FA：用户自主关闭前须验证当前登录密码（或当前有效的 6 位 TOTP 码）。

## 3. 全端统一文案规范（对齐 OneNote）

| 操作场景 | 统一文案 | 禁止使用的模糊文案 |
| :--- | :--- | :--- |
| 新建笔记本 | **`添加笔记本`** | ~~新建笔记本~~ |
| 新建分区 | **`添加分区`** | ~~新建分区~~ |
| 新建页面 | **`添加页面`** | ~~记一页~~ / ~~新页面~~ |
| 新建子页面 | **`添加子页面`** | ~~+ 子页面~~ |
| 新建空页面正文提示 | `placeholder`: **`随时记下此刻的想法...`** | 严禁作为正文文本写入编辑器内容 |
| 新建空页面标题提示 | `placeholder`: **`无标题页面`** / **`页面标题`** | — |
