## 1. 视觉风格定位：「晶莹剔透 · 琉璃微光」

在 V1（晨雾极简）的基础上升级至 V2–V4.1 的 **Liquid Crystal（液态琉璃）** 美学体系——既让人「眼前一亮、晶莹剔透、布灵布灵」，又严格遵守阅读与长文写作的视觉舒适底线：

### 1.1 双主题色板与材质规范
| 视觉元素 | 冰晶晨露（浅色主题） | 星钻夜幕（深色主题） |
| :--- | :--- | :--- |
| **底层极光底色** | `#EEF3FF` + 缓慢漂移的冰蓝/淡紫/樱粉/薄荷柔光球 | `#070B1A` + 深海青/星紫/玫红极光微光与星点 |
| **悬浮琉璃侧栏** | `rgba(255, 255, 255, 0.65)` + `blur(28px) saturate(185%)` | `rgba(17, 24, 48, 0.60)` + `blur(28px) saturate(185%)` |
| **高澄澈编辑画布** | `rgba(255, 255, 255, 0.84)`（保障高对比久看不累） | `rgba(16, 23, 45, 0.78)` |
| **双层折射描边** | 1px 棱镜渐变高亮描边 + 顶部白色内高光 | 1px 冰蓝星紫渐变半透描边 |
| **品牌主色** | `#6366F1`（渐变 `#6366F1 → #8B5CF6 → #38BDF8`） | `#818CF8`（渐变 `#818CF8 → #A855F7 → #38BDF8`） |
| **主/次文字色** | `#141B34` / `#435073` / `#7C89AC` | `#F1F6FF` / `#B4C2E4` / `#7687B2` |

- **光效强度两档可调**：支持用户在个人菜单中切换 **`璀璨`**（完整极光、星芒粒子与微光）与 **`柔和`**（降低极光透明度、隐藏环境星点与入场扫光，适合极度沉静专注）。
- **宝石切面分区色板（8 色循环）**：`#6366F1`（星海靛）、`#06B6D4`（冰川蓝）、`#EC4899`（樱花晶）、`#10B981`（薄荷翡）、`#F59E0B`（琥珀蜜）、`#A855F7`（紫晶）、`#F43F5E`（珊瑚红）、`#3B82F6`（晴空蓝）。

### 1.2 克制的「布灵布灵」微交互规则（已定稿）
1. **主按钮扫光规则**：**严禁无限循环扫光**（会分散写作注意力）。定稿为：**进入页面或切换大视图时轻扫一次 + 鼠标悬停（Hover）时触发一次光泽掠过**。
2. **鼠标追光折射（桌面端）**：指针滑过琉璃面板与卡片时，表面呈现柔和的径向玻璃高光追踪。
3. **愉悦微光粒子反馈**：勾选待办清单、点击星标置顶、新建条目、切换主题时，在触点绽放 6 颗轻盈星芒粒子（`✦`/`✧`），柔和模式下自动关闭。

## 2. 正式版导航架构（已定稿）

> [!IMPORTANT]
> 原型顶部黑色「原型评审工具栏」仅供设计评审切换预览，**正式版本完全不存在**；正式版也绝不在主界面放置「登录/2FA」伪导航入口。

### 2.1 未登录态
- 全屏独立登录页（居中琉璃卡片）：输入账号密码；若该账号开启了 2FA，平滑切换为 6 位数字验证码输入（支持粘贴与备用恢复码切换）。页面底部提示「仅限受邀成员使用，如需账号请联系管理员」。

### 2.2 桌面端（已登录，`>= 768px`）
- **无多余顶部大导航栏**，视口 100% 留给 **悬浮间距三栏**：
  1. **左栏（256px）**：顶部 `AirNote` 徽标 + `⌘K` 搜索键；笔记本下拉切换浮层（内含 `+ 添加笔记本`）；分区列表（含数量与 `+ 添加分区`）；底部用户头像条。
  2. **中栏（272px）**：当前分区名 + **`+ 添加页面`** 主按钮；分区内页面筛选框；页面卡片流（含子页面缩进与星标）。
  3. **右栏（自适应）**：面包屑（支持一键切换 **沉浸专注模式** 收起左右双栏）、实时同步提示、星标、`+ 添加子页面`；悬浮格式化工具条；最大宽度 `740px` 居中阅读/写作画布。
- **左下角用户头像弹出菜单**统一收纳：
  - `安全与 2FA 设置`（弹窗）
  - `切换深浅外观`
  - `光效强度（璀璨 / 柔和）`
  - `管理员控制台`（**仅 `role === 'admin'` 渲染，普通用户完全不可见**）
  - `退出登录`

### 2.3 移动端（手机浏览器，` < 768px`）— 纯净四级钻取 UE

彻底取消底部 4 Tab 栏，把纵向空间还给内容；右上角圆形个人头像统一呼出底部菜单（Bottom Sheet，含安全与 2FA、深浅外观、管理员控制台 [仅管理员]、退出登录）。

| 层级 | 页面定位 | 核心布局 | 底部唯一居中悬浮主按钮 |
| :--- | :--- | :--- | :--- |
| **L1 笔记本（首页）** | 纯粹的笔记本书架（**不混排分区**） | 顶部 `AirNote` + 搜索 + 头像；「★ 星标置顶」直达卡片；笔记本大卡片列表（大图标、名称、分区/页数、彩晶色点预览） | **`+ 添加笔记本`** |
| **L2 分区** | 某一本笔记本的专属分区列表 | 顶部 `‹ 笔记本` 返回；当前笔记本标题；分区快速筛选框；整屏纵向彩晶分区列表（轻松承载 20–30+ 分区） | **`+ 添加分区`**<br>（100% 归属当前笔记本） |
| **L3 页面** | 某一分区的专属页面流 | 顶部 `‹ 笔记本名` 返回；可点击的分区标题 **`● 分区名 ▾`**（一点呼出双列宫格快切同笔记本其他分区）；页面卡片 + 右侧 `⋯` 操作菜单 | **`+ 添加页面`**<br>（100% 归属当前分区） |
| **L4 编辑页** | 全屏沉浸式读写 | 顶部 `‹ 分区名` 返回 + 同步状态 + 星标 + `⋯` 更多菜单；大字号正文；底部贴合输入法的拇指格式化栏（`H2` / `☑ 待办` / `💎 卡片` / `</>` / `完成`） | 底部工具栏 |

## 3. 原型评审阶段沉淀的工程避坑清单（开发必守）

以下均为原型打磨阶段实测发现并修正的关键细节，正式 React + Tailwind 开发时务必严格遵守：

1. **禁止全局工具类覆盖绝对定位**：自定义玻璃态/按钮类（如 `.crystal-card`、`.btn-crystal`）不得无条件声明 `position: relative`，避免覆盖 `absolute`/`fixed` 导致下拉浮层撑开容器或底部悬浮按钮偏移。
2. **桌面端下拉菜单必须浮层化 + 内部滚动**：笔记本切换下拉框与底部用户菜单均采用独立悬浮浮层（带 `max-h` 内部滚动），绝不挤压下方分区列表。
3. **移动端底部悬浮主按钮居中对齐**：使用 `absolute bottom-5 inset-x-4 flex justify-center pointer-events-none` 包裹 `pointer-events-auto` 胶囊按钮，适配 `env(safe-area-inset-bottom)`，左右手拇指皆顺手。
4. **编辑器空白提示语必须为真 Placeholder**：新建页面/分区/笔记本时正文初始化为空文档，提示语「`随时记下此刻的想法...`」通过 TipTap `Placeholder` 扩展渲染，绝不可写成真实文本节点。
5. **移动端防 iOS 自动缩放与触控热区**：所有移动端 `<input>` / 编辑器字号不低于 `16px`（防止 iOS Safari 聚焦自动放大页面）；所有可点按钮热区至少 `36×36px` ~ `44×44px`。
6. **手机端 2FA 绑定适配**：手机访问时用户无法扫描本机屏幕二维码，自动优先展示「一键复制 Base32 密钥」与 `otpauth://` 直连按钮，二维码改为可展开辅助项。
7. **手机端补齐无右键操作**：每个页面卡片与编辑页均提供显式 `⋯` 按钮，呼出 Bottom Sheet 执行「添加子页面 / 置顶 / 移动到其他分区 / 移至回收站」。
